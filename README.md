### Backend Developer focused on AI Chatbot & Workflow Automation

백엔드 개발과 AI 챗봇 시스템 개발에 집중하고 있는 개발자입니다.  
Node.js, TypeScript, Express, PostgreSQL 기반의 서버 개발과  
LINE, Slack, WooCommerce API를 연동한 고객 응대 자동화 시스템 개발 경험이 있습니다.

단순 기능 구현보다 실제 운영 흐름을 이해하고,  
고객 문의, 주문 상태, 내부 담당자 대응 과정을 연결하는 백엔드 시스템 설계에 관심이 있습니다.

일본 실무 및 생활 경험을 바탕으로 일본어 커뮤니케이션이 가능하며,  
일본 고객 대상 서비스와 글로벌 운영 환경에도 관심을 가지고 있습니다.

## 📌 Main Experience

### AI Chatbot System for Customer Support

LINE과 Slack을 연동한 고객 응대 자동화 챗봇 시스템을 설계하고 개발했습니다.

- LINE 메시지 수신 및 자동 응답 처리
- Slack 채널별 알림 및 담당자 대응 플로우 구성
- GPT API 기반 자연어 응답 처리
- 고객 문의 유형 분류
- 주문 상태 및 고객 데이터 기반 응답
- 관리자 승인 / 거절 / 직접응답 흐름 설계

<br/>

### WooCommerce Order Integration

WooCommerce 주문 데이터를 기반으로 고객 응대와 주문 상태 관리를 자동화했습니다.

- WooCommerce 주문 상태 조회
- 주문 상태별 고객 안내 메시지 구성
- 결제 상태 변경 감지
- 외부 API 연동
- 주문 데이터 기반 챗봇 응답 처리
- 관리자용 주문 처리 기능 개선

<br/>

### LINE / Slack Workflow Integration

고객 채널과 내부 운영 채널을 연결하는 업무 플로우를 설계했습니다.

- LINE 고객 메시지 수신
- Slack 내부 알림 전송
- 담당자 확인 및 수동 응답 플로우
- 채널별 문의 분류
- 반복 문의 자동화
- 운영 효율 개선
